# swizzle-site

The Swizzle landing page. Astro renders it to static HTML at build time; `src/scripts/page.js` adds the motion.

```bash
npm install
npm run dev                                  # http://localhost:4321, also on the LAN/tailnet
SITE_URL=https://<domain> npm run build      # type-check, then static output in dist/
```

The build needs `SITE_URL`, because canonical links, Open Graph tags, robots.txt and the sitemap carry the public origin. `BASE_PATH` is set only when the site is served from a subpath.

## Deploy

`.github/workflows/deploy.yml` builds every push and pull request and publishes `main` to GitHub Pages. It takes the URL from the Pages settings, so the site moves from `swizzletech.github.io/swizzle-site` to the own domain without a code change:

1. Verify the domain for the `swizzletech` org (Settings, Pages, Add a domain) and add the TXT record GitHub shows. This stops anyone else from claiming it on Pages.
2. At the registrar, point the apex at GitHub Pages: `A` records `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`, `AAAA` records `2606:50c0:8000::153` to `2606:50c0:8003::153`, and `www` as `CNAME` to `swizzletech.github.io`.
3. In the repo's Pages settings, enter the domain, wait for the certificate and turn on Enforce HTTPS.
4. Rerun the Deploy workflow so canonical links and the sitemap carry the new origin.

## Legal pages

`/impressum/` and `/datenschutz/` read the provider from `src/legal.ts`. The Datenschutzerklärung is short because the site has no cookies, no analytics, no embeds and self-hosted fonts; adding any of those means updating it.

## Layout

- `src/pages/index.astro`: the page and all of its copy. Product claims follow Swizzle 1.0 (README, CHANGELOG and docs in swizzletech/swizzle).
- `src/pages/impressum.astro`, `src/pages/datenschutz.astro`: the legal pages, in German, on `src/layouts/Legal.astro`.
- `src/layouts/Base.astro`: head tags and self-hosted fonts (Fontsource, no request to Google).
- `src/path.ts`: prefixes internal links with the deploy base.
- `src/art/`: the illustrations as SVG strings, inlined at build time. `device-art.js` is generated by `tools/device-gen.py`; change the generator, not the output.
- `src/scripts/`: the typing terminal, the shader suns, the page band (`bands.js`) and the run on the track.
- `public/og.png`: the link preview image, a 1200×630 capture of the hero.

The design rounds that led here live outside this repo, in the sketches folder of the design workspace.
